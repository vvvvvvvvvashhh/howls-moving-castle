# 《风起，城行》逆向提示词

## 短版

```text
请用程序化三维制作一部 60 秒的《哈尔的移动城堡》致敬短片，给我可离线打开的 Three.js 互动版、可编辑源码和可逐帧渲染的 Blender 工程。
从低处的花海随乌鸦升高、掠过城门、飞向小镇，切入厨房看卡西法跳进火盆，再看芜菁头托着它走过草地。城堡随后穿过春花、夏湖、秋林、冬雪。
最后 20 秒一镜到底。从同一侧跟住城堡，拍清四足压地、两翼错拍张开、排汽和尘土、逐脚离地，以及横风中的左右回摆。天色渐暗再亮，镜头从侧面绕到后方。
清晨让城堡在画面上方低飞，芜菁头在下方追，卡西法从掌中木柴上单独弹起。横屏 16∶9、24 帧/秒。请一并交付分镜、运行说明和源码中可改动这些动作的位置。
```

## 完整工程版

下面整段可以直接复制。随手头材料附上互动 HTML、`.blend`、成片或参考图，能进一步指定你想保留的轮廓、机位和动作。

```text
请制作一部横屏三维短片《风起，城行》，以《哈尔的移动城堡》为造型参考。镜头先跟一只乌鸦找到这座会走路的家，最后从空中找到在地上追赶它的两个伙伴。作品长 60 秒，16∶9，成片规格为 1920 × 1080、24 帧/秒，共 1440 帧。若附有原工程或参考片，请用它对照城堡的脸、桅顶、屋门、机械脚以及结尾的人物位置。

一、先让城堡在远近两个距离都认得出来

先搭船腹、锅炉、屋群和四条机械腿。船首有伸出的红褐色护甲、圆形观察孔和内凹的炉口。铁壳的接缝顺着曲面走，瓦片顺坡叠放。屋群之间用外梯、平台、管道相连，上方留出几根高低错落的烟囱和一根可辨的桅杆。两侧是可收拢的帆翼，尾部有螺旋桨。远看轮廓偏重，近看能分清磨旧的铁、黄铜、木料、灰泥和瓦。把会动的机件做成独立节点，为足底、门侧、桅顶、烟口和人物掌心留出锚点。

二、沿这条时间线拍

0–22 秒。贴着高地花草向城堡前进。约 5.75 秒乌鸦拔高，随后俯冲，从城门旁掠过，飞向红屋顶街道。鸟的路线、机位和注视点各自可调。摄影机晚三四帧追上鸟的转弯，掠门时收小延迟，近看门框，离开小镇前让钟楼接住视线。

22–30 秒。切进厨房。卡西法望向有两片劈柴的小铁盆，约 23.57 秒起跳、24.31 秒落到木柴上。盆沿随落地轻晃。25 秒切到户外，芜菁头右掌稳稳托盆，空着的手打招呼。它靠脚下的木杆一跳一跳地前进，帽檐、衣摆和火尖比身体晚半拍。

30–40 秒。春、夏、秋、冬各占 2.5 秒。春是成片花树和花瓣，夏是湖湾、岸边绿荫，秋是金红树冠和落叶，冬是雪原、针叶树和屋顶积雪。切景时延续城堡在画面中的行进方向、步相和摄影机角度。地面跟着行进距离向后移，近处比远山掠得快。

40–60 秒。用一个连续的跟拍镜头。先从上一拍的同一侧、同一视角接住城堡。城堡向画面左侧越过沙丘，远处能看见城镇。摄影机降低、稍稍靠近，看清脚下，再随起飞抬高。沿一条连贯的弧线从侧面绕到城堡身后，始终给前进方向留出空间。浅蓝天空转入暮色，窗灯和星光逐渐显出，将深蓝夜色留够一拍。约 54.1 秒，日轮从城堡右侧的低空升起。接着向下俯，先从下沿露出芜菁头的帽尖，再看见它的全身。最后城堡在上方低飞，芜菁头在下方追，二者中间看得见草地。盆底始终跟掌心走，卡西法在柴火上方有几次高低不同的独立小跳，最后落回。

三、把城堡的重量拍出来

按已经走过的距离驱动步态。单脚约四分之三的周期用于承重，支撑时足底钉在地面同一点，身体先向其他三脚移重，摆动脚再抬起、送出、触地。用逆向运动学求髋、膝和踝的位置。铁壳保持厚重，碰地的冲击由机身的轻沉与回弹接住。

42 秒以后逐步收步、屈膝，机头前俯，压到最低处停约四帧。在屈膝的过程中，43.02 秒近侧翼帆先展，约八帧之后另一侧跟上，接着让两侧阀口先后排汽。让右前、左前、左后、右后足在 44.03 至 44.40 秒间依次卸重，脚边尘土向外散，离地的脚向后摆过一次。约 47.35、49.45、51.80 秒依次向两侧倾斜，幅度约为 +10°、−10°、+8°。悬足、帆尖、桅杆和烟囱分别追上机身，摄影机只跟少量横滚，让观众有地平线可参照。蒸汽从阀口散开，尘土留在脚下原先接触地面的地方，碎屑从屋檐落下，各自沿世界坐标运动。

四、把同一套动作做成两种可用的工程

Three.js 版提供固定版本的渲染库、可离线打开的单文件 HTML 和按模型、人物、场景、摄影机、时间轴拆分的可编辑源码。网页支持播放、暂停、重播、章节跳转、拖动时间轴、自由环视和缩放。默认可静音播放，也能选取本地音频跟随进度。跳到同一时刻，应得到相同的相机、足位、人物和粒子状态。

Blender 版使用 Cycles。把几何、贴图、物体层级、相机和逐帧动作导入原生场景。统一坐标和垂直视角，将会编辑的机件和角色保留为对象或形态键。用原生材质、照明和烟尘完成画面，输出连续的无损 PNG。若按本作的质感收尾，浏览器可在画布上轻微增色，Blender 的 AgX 输出在编码时只增加一次色度，最高约 8%，保护原亮度和炉火高光。

五、用这些画面判断是否做对了

在正常速度和逐帧两种情况下看跟鸟转弯、四脚承重、起飞和晨光收尾。对照前后帧，确认季节切换时城堡仍向同一方向走，尾镜头绕到后方的过程连续，火苗可离开木柴而火盆仍在掌中。将时间轴从头、从尾分别拖到同一秒，检查角色和摄影机能回到同一位置。

另取开场相邻五帧，跟踪近草、城堡漆面和远树边缘。可从基础 16 采样、炉火与暗夜段 32 采样起步，给远景雾使用抗锯齿的 Mist 渲染通道，并按天空覆盖比例处理轮廓。逐帧比较时避开剪辑点，保留真实的拍翅、阵风和天光变化。编码后核对时长、帧数和首尾动作。

```
